# 星空战机 · Star Fighter

> 赛博朋克霓虹风纵版弹幕射击 · 纯原生 Canvas 单文件实现 · 零依赖零构建

🎮 **在线试玩**：https://xingkong-zhanji.pages.dev

## 玩法特性

- **10 大关卡**：敌军强度逐关递增，每关 28 秒（随难度变化）波次后迎来首领战
- **三大 Boss 轮换**：先锋战舰（瞄准散弹）/ 钢铁要塞（环形弹）/ 终极母舰（混合弹幕），各带二阶段狂暴
- **四档难度**：简单 / 普通 / 困难 / 噩梦，同时缩放敌血、敌速、伤害、Boss 节奏，高难度高收益（金币最高 ×1.7）
- **战机机库**：三种战机（免费侦察型 / 疾风型 / 重炮型），金币解锁，双人模式自动换色
- **成长系统**：金币掉落磁吸、武器升级、护盾、商店三系强化、15 项成就
- **双人同屏**：P1 鼠标/WASD，P2 方向键
- **手机触控适配**：手指上方偏移跟手操作

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | 鼠标 / 触控 / WASD / 方向键 |
| 射击 | 自动开火（可关） |
| EMP 清屏 | Q |
| 暂停 | P / Esc |
| 音效 | M |

## 技术

- **单文件架构**：全部逻辑在 `index.html`（约 1500 行），`assets/` 仅 8 张单位图标
- **图标管线**：黑底/白底/照片天空底（漫水填充）三种自动抠图 + 旋转裁切，离屏预渲染
- **性能**：全部发光效果预渲染贴图，无每帧 shadowBlur；极限负载实测单帧 <0.3ms
- **音效**：WebAudio 合成（柔和渐入包络，耳机友好）
- **存档**：localStorage，按设备独立，无需注册登录点开即玩
